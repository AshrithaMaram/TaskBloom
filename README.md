# 🌸 TaskBloom — Daily Planner & Focus Timer

TaskBloom is a colorful productivity web application that helps you organize daily tasks, track completed work, and improve concentration with a customizable focus timer.

## ✨ Features

- 📅 **Interactive Calendar:** Navigate between months and select individual dates.
- ✅ **Daily Task Management:** Add, edit, complete, and delete tasks.
- 🗓️ **Task History:** Revisit previous dates to review tasks and their completion status.
- 🔎 **Task Filters:** View all, pending, or completed tasks.
- 📊 **Daily Progress:** Track total, completed, and pending tasks.
- ⏱️ **Customizable Focus Timer:** Choose a duration from 1 to 180 minutes.
- ▶️ **Timer Controls:** Start, pause, resume, and reset focus sessions.
- 🔔 **Completion Alarm:** Hear an electronic alarm for approximately 20 seconds when a session finishes.
- 💬 **Motivational Quotes:** Display inspirational quotes to encourage consistent progress.
- 🏆 **Focus Session Counter:** Track completed focus sessions.
- 💾 **Browser Storage:** Save tasks and completed-session counts using Local Storage.
- 🎨 **Responsive Interface:** Enjoy a bright pink, purple, and pastel-inspired design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Browser Local Storage

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to preview the application.

## 💾 Data Storage

TaskBloom stores tasks and completed-session counts in the browser's Local Storage.

Your saved data is normally available when you reopen the app in the same browser on the same device. It is not automatically synchronized across browsers or devices, and clearing browser data may remove it.

This project was created to practise frontend development, DOM manipulation, event handling, date-based task organization, browser storage, and timer functionality.
